These 8 functional areas are sufficient to practice almost all the important Angular concepts:

Book Listing       → RxJS, Signals, HTTP, Forms
Book Details       → Routing, Lifecycle, Components
Book Management    → Reactive Forms, Validation
Cart               → State Management, Signals
User/Login         → Guards, Interceptors, JWT
Orders             → HTTP, Forms, Routing
Reviews            → Forms, Custom Components
Admin              → Lazy Loading, Guards, Architecture

Then we can deliberately introduce interview scenarios such as:
  1.  Search → debounceTime + switchMap
  2.  Cart → Signals
  3.  API → HttpClient + Interceptors
  4.  Login → JWT + Guards
  5.  Book form → Reactive Forms + Custom Validators
  6.  Book list → OnPush + track
  7.  Admin → Lazy Loading
  8.  Large book list → Performance optimization
